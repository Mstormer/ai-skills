# Biblical Hebrew & Greek Mnemonic Creator

An AI agent skill that gives you seven English sound-alike mnemonics for any Biblical Hebrew or Koine Greek word, ordered from closest to furthest sound match. Each row of the table has the mnemonic, why it fits the word's meaning and sound, and a storyboard scene to picture.

## Install

Copy this folder into your AI agent's skills folder (for example `~/.claude/skills/` or `~/.agents/skills/`), or give `SKILL.md` to any AI assistant as instructions. Then give it a word, ideally with its definition, for example: "Mnemonics for רָעָב (famine)".

## Images

Give a row number (1–7) and the skill turns that row's storyboard scene into an image with an image tool if you have one connected, and otherwise gives you the scene as a prompt for any image generator.
