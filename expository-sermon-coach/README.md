# Expository Sermon Coach

An AI agent skill that coaches preachers through text-faithful expository sermon preparation using Haddon Robinson's Biblical Preaching method. It works through seven stages (choose the passage, study it, determine the Big Idea, outline, apply, introduce and conclude, illustrate) and can also start at a single point: subject and complement, bullet refinement, manuscript critique or illustration coaching. It coaches with questions and criteria; it doesn't write the sermon for you.

## Install

Copy this folder into your AI agent's skills folder (for example `~/.claude/skills/` or `~/.agents/skills/`), or give `SKILL.md` to any AI assistant as instructions. Then say: "Help me develop a sermon from Romans 8:1–11."

## Use

Reply "Next Step" to move on or "Give me an Example" for a provisional example of the current step.
