# Bible Framework Explorer

An AI agent skill that guides you through a fourteen-category hermeneutical framework (theology proper, Christology, soteriology, ontology, metaphysics, epistemology, anthropology, ethics, teleology, missiology, eschatology, cosmology, logic and hermeneutics) to find the affirmations and presuppositions evident within a biblical text. It asks only questions, one category at a time, and gives example answers when you ask. It can also demo the whole process on a passage. Bible references are linked to STEP Bible in several versions side by side.

## Install

Copy this folder into your AI agent's skills folder (for example `~/.claude/skills/` or `~/.agents/skills/`), or give `SKILL.md` to any AI assistant as instructions. Then say: "Demo the Bible Framework Explorer with Genesis 3:6" or "Guide me through the Bible Framework Explorer with Romans 5:1–11."

## Use

After each category, reply "Next" to continue or "Example" for example answers. After the last category you are asked to summarize your findings.
