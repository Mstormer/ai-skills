# AI Tools and Skills

A collection of hooks, skills and small tools for AI coding agents such as Claude Code and Codex. Each tool lives in its own folder with its own install guide, written so that an agent can install it by itself.

## Tools

| Tool | What it does | Platforms |
|---|---|---|
| [PreToolUse Safety Hooks](PreToolUse%20Safety%20Hooks/) | Blocks shell commands that would wipe a disk, the operating system or an important folder, before the agent runs them. | macOS, Linux, Windows |

## Installing a tool

Open the tool's folder and follow its `INSTALL.md`, or point your agent at it, for example:

> Install the tool in `PreToolUse Safety Hooks/` by following its INSTALL.md.
